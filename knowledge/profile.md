## Project: Klaro
Klaro is a generative AI document summarizer built with React, Node.js, Express and Multer. Uploaded PDFs and scanned images are routed by file type to pdf-parse or Tesseract.js OCR, then passed to a generative AI API. Prompts are engineered around the user's chosen summary length to return structured, actionable summaries through a drag-and-drop frontend. It can use Google Gemini and has a deterministic fallback when no API key is set. Code: https://github.com/VeerDev-hub/Klaro

## Project: PulmoSight
PulmoSight is a research project on explainable tuberculosis screening from chest X-rays, built with Python, PyTorch, Flask and Grad-CAM. An ImageNet-initialized EfficientNet-B0 adapted for grayscale X-rays classifies images as TB or Normal, using 16,807 Indian chest X-rays (13,445 training, 3,362 validation). The best checkpoint reached a validation AUROC of about 0.9385, and the project also evaluates sensitivity, specificity, calibration and threshold trade-offs. Grad-CAM heatmaps show which regions influenced a prediction. PulmoSight is a screening-support prototype: it is not clinically validated, not a medical diagnosis, and does not measure severity or confirm lesion location. Code: https://github.com/VeerDev-hub/PulmoSight
