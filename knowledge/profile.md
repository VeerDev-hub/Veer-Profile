## Project: Klaro
Klaro is a RAG-powered document assistant built with React 19, Vite, Node.js and Express. It summarizes any PDF, scanned image or text file, then lets the user chat with it and get cited answers. Text is extracted with pdf-parse for PDFs and Tesseract.js OCR for scans, then two pipelines run in parallel. Indexing splits the text into overlapping 1,500-character chunks, embeds them with gemini-embedding-001 (768 dimensions) and stores them in Pinecone, one namespace per document. Summarization reads the whole document in one long-context Gemini call, or uses map-reduce over sections for very large files, with structured JSON output and three summary lengths. Chat answers stream token by token over Server-Sent Events, use only retrieved passages and include clickable [n] citations. Every dependency has a fallback: ordered Gemini model fallback, 429 retry handling and a labelled extractive summary when the AI is unavailable. The backend follows a routes, controllers and services layering with helmet, a CORS allow-list, rate limiting and in-memory uploads, and has a node --test suite. It also offers light, dark and sepia themes, text-to-speech and export to PDF, Markdown, TXT and JSON. Live: https://klaro-74eckmgt8-nextn-exus.vercel.app/

## Project: Overlap
Overlap is a collaboration network for builders anywhere, built with React 19, Vite, Tailwind CSS, Node.js, Express, Socket.io, WebRTC, Neo4j and MongoDB. It began as VITAP Connect, a network for one university campus (VIT-AP), and Veer rebuilt it for a global audience. Anyone can sign up with an email one-time code, and school emails get a verified-student badge. Profiles list skills, languages, timezone, experience level and what the person is open to (hackathons, side projects, startups, open source, research, mentoring, freelance). A Neo4j graph query scores people to work with on shared skills, interests and goals, field, mutual connections, language, country and working-hour overlap, and every suggestion explains why it was made. Cards show each person's local time, profiles show a day-overlap strip, and a team clock shows which connections are awake. Users create projects with join requests, team channels and call rooms, and projects move from recruiting to building to shipped; shipping a team project unlocks another project slot. There is a feed with photo and video posts, public profiles with work history, and direct, group and project chat over Socket.io with typing indicators, read receipts, edit and unsend. Messages are encrypted at rest with AES-256-GCM, and voice and video calls with screen sharing use WebRTC. Compared with VITAP Connect, Overlap hardens security: OTPs from crypto.randomInt with rate limits, session checks on HTTP and sockets, private emails, strict avatar uploads and validation of every field. It runs offline in Docker with a seeded 13-person demo community from 13 countries and deploys on Render.

## Project: NEXUS-SOC
NEXUS-SOC is a multi-agent Security Operations Center in which a team of seven AI agents investigates every alert end to end while human analysts stay in control. It is built with Python, Django, Django Channels, Pydantic, Next.js 16 and Tailwind CSS 4, and runs in Docker. A Supervisor agent routes each case through Triage, Threat Intel, Asset & Identity, Investigation, Response and Reporting specialists; guardrails reject illegal routes. Each specialist calls tools (threat-intel feeds, CMDB, SIEM search, knowledge base) and fills a typed Pydantic schema. Agents only propose containment actions: the risk tier comes from policy, and Medium, High and Critical actions need approval from a Tier-2 Incident Responder or the SOC Manager. There are five roles (SOC Admin, SOC Manager, Tier-1 Analyst, Tier-2 Incident Responder, Auditor), each with its own home page and permissions enforced on every API endpoint. Live log detection reads syslog, log files and the Windows Event Log with 38 signature rules and 3 behavioural (UEBA) rules mapped to MITRE ATT&CK. It works with cloud models (OpenRouter, DeepSeek, OpenAI, Gemini), a local Ollama model, or a built-in offline rule engine, failing over automatically. Guardrails flag prompt injection in log text, require actions and IOCs to be grounded in evidence, and cap token spend. Every decision, tool call, model, token count and approval is stored in a Decision Trail and Audit Log, alert emails go out for confirmed incidents, and the agents are benchmarked on labelled attack scenarios as part of research paper work.

## Project: PulmoSight
PulmoSight is a deep learning research project that classifies a frontal chest X-ray as TB or Normal and returns a calibrated probability, built with Python, PyTorch, EfficientNet-B0, Jupyter and Streamlit. It compares three CNNs trained on the same 13,445 X-rays: a Simple CNN (5 conv blocks, 0.39 M parameters), PulmoNet (a custom residual squeeze-excite CNN, 4.1 M) and an ImageNet EfficientNet-B0 (4.0 M). A weighted ensemble (EfficientNet-B0 50%, Simple CNN 30%, PulmoNet 20%) of temperature-calibrated probabilities reached 86.7% test accuracy and 0.937 AUROC on 1,681 held-out test X-rays, with 80.6% sensitivity and 92.6% specificity, and cut false alarms from 105 to 64 compared with EfficientNet-B0 alone (85.4% accuracy, 0.933 AUROC). Every choice (early stopping, calibration, thresholds, ensemble weights) was made on 1,659 validation images, and the test set was scored once, with bootstrap confidence intervals, DeLong and McNemar tests. The project also studies overfitting, robustness to image corruptions and shortcut learning, including a lung-segmentation retraining experiment. A Streamlit app lets anyone test an X-ray, compare the models and see image-quality warnings. PulmoSight is a research prototype: it is not a medical device and not a diagnosis. Code: https://github.com/VeerDev-hub/PulmoSight

## Project: Analytica Studio
Analytica Studio 2.0 is a multi-user web platform for getting tabular data ready for machine learning. It rebuilds Veer's original single-user Streamlit app with a React frontend, a FastAPI API, Celery workers, PostgreSQL, S3 storage, DuckDB, pandas and scikit-learn, deployed on AWS (ECS Fargate, RDS, ElastiCache, S3, CloudFront) with Terraform. Users upload a CSV, Excel or Parquet file and move through Data, Explore, Clean, Features, Validate and Export pages. Every pipeline step creates an immutable Parquet version with undo, redo and reusable recipes. Encoders, scalers, imputers, PCA and resampling such as SMOTE are fitted on the training split only, which prevents leakage. Validate runs readiness checks and quick baseline models. Export produces the data as CSV, Parquet, Excel or NumPy, plus a standalone pandas/scikit-learn script or notebook that reproduces it exactly. A Gemini-powered assistant answers questions about the data, and every number comes from a read-only SQL query in a sandboxed DuckDB, shown with the answer. It also has email and OAuth sign-in, plans, rate limits and an admin console. Code: https://github.com/VeerDev-hub/Analytica

## Project: Recon Console
Recon Console is an Nmap-style network reconnaissance engine Veer wrote from scratch in Python, using only the standard library for scanning (no Scapy, no nmap) and Flask for the web console. It builds and decodes IPv4, TCP, UDP and ICMP packets by hand, including checksums, pseudo-headers and fragmentation. It supports TCP connect, SYN, FIN, NULL, XMAS, ACK, Window, Maimon and UDP scans, host discovery, service and version detection, OS fingerprinting and offline CVE matching. A live web console streams progress and findings over Server-Sent Events and diffs each scan against the previous one. Reports export to CSV, JSON, XML, Markdown and HTML. By default it only scans loopback and private ranges unless the user confirms they are authorized. It has 34 offline tests and runs in Docker. Code: https://github.com/VeerDev-hub/Port-Scanner

## Project: Pixel Pet
Pixel Pet is a free, open source desktop pet for Windows, macOS and Linux that Veer co-built as a two-person project in Rust. It is a tiny pixel pet that walks around the desktop and keeps the user on task, shipped as a single 1.8 MB exe with no installer, no account and no telemetry; on Windows 11 it idles at about 17.6 MB of memory and 0.02% CPU. It has a natural-language task list ("call mom tomorrow 5pm", "standup weekdays 9:30"), a Pomodoro focus timer with streaks, stats and do not disturb, calendar reminders from .ics or Google Calendar and Outlook links, break reminders, live network speed, CPU and memory, a GitHub Actions build watcher, and alerts when big downloads finish. The pet walks, does tricks, can be stroked, thrown and fed, walks on windows and across monitors, dances to music and changes with the time of day and the seasons. There are forty pets, twenty-four original heroes and villains with powers, a character maker and shareable .petpack character packs. It is built directly on each platform's windowing API: windows-sys (Win32) on Windows, x11rb on Linux and objc2 (AppKit) on macOS. Its website runs on Cloudflare Pages Functions with a D1 database for downloads, feedback and the pack gallery. Website: https://pixel-pet.pages.dev Code: https://github.com/VeerDev-hub/pixel-pet
